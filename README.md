# multitenant-auth-api
Projeto de um backend de uma Plataforma Multi-tenant de Autenticação e Autorização (IAM / Auth API) escrita em Java, Spring Framework, Maven e JUnit. Um serviço central de identidade que emite tokens, gerencia usuários, perfis de acesso (RBAC - Role-Based Access Control) e permite login seguro para múltiplas aplicações, microsserviços ou clientes.
